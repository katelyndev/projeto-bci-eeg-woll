# Gravações EEG — Análise da Onda Delta

## Objetivo

Estas gravações são utilizadas no projeto BCI/EEG para estudar a potência da onda Delta durante a vigília e o sono profundo, além de validar a qualidade dos sinais registrados.

## Arquivos

**Participante 1**
- `SC4001E0-PSG.edf` — gravação polissonográfica.
- `SC4001EC-Hypnogram.edf` — identificação dos estágios do sono.

**Participante 2**
- `SC4011E0-PSG.edf` — gravação polissonográfica.
- `SC4011EH-Hypnogram.edf` — identificação dos estágios do sono.

## Origem dos dados

Sleep-EDF Database Expanded, disponibilizado pelo PhysioNet.

## Utilização no projeto

Os arquivos são utilizados para:

- Analisar a potência Delta (0,5–4 Hz).
- Comparar sinais de vigília e sono profundo.
- Verificar a qualidade dos sinais EEG.
- Investigar possíveis interferências e problemas nos canais.

As gravações originais devem ser preservadas sem modificações.
